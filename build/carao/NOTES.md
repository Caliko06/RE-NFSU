Output: `carao.bin` 1.8 MB (1.4 MB gzip), 6607 solids, 1.77 M vertices, u8 per vertex. Missing: decals, engines, WIDE decals (AO 1).
Cost (Blender 5.2 Cycles, Metal, 4096 spp, dist 0.3 m since OWNER 'subtle only': creases, not whole-car shade; `DIST=0.3 bakeall.sh`): 22-34 s per car (88 assemblies x ~0.3 s), ~8 min for all 20. Rebuild: `bakeall.sh; for c ...; consolidate.py $c; pack.py`. Offline only, zero runtime cost beyond one hash per draw.
17 race rows (build/pod/ao/mesh): they hold the AO of the 5067 draws they saw, keyed by vertex-buffer hash, but only 7 kit cars (ECLIPSE FOCUS IMPREZA NEON RSX SENTRA SKYLINE), 76 kit/style solids, LOD A, the kit combos each run happened to draw (cover.py). They do NOT cover all kits. carao.bin does.
Draws are whole solids: all 5067 runtime draws = vertex range of one solid (slices.py), so the key is simple: key = FNV-1a 64 over the 12 position bytes of vertices 0..nv-1 (same bytes as GEOMETRY.BIN, stride 36). 332 key clashes = identical hoods reused under two STYLE numbers, AO differs ~3 %, benign.
Carrier: COLOR0 (offset 24 of the 36-byte vertex). It is 0xff000000 on body/kit (w2 trace; car.efx never reads it), and carsmooth output copies vertex 0's tail bytes anyway. Write AO in the ALPHA byte (original alpha 0xff = "open", so unmatched cars/parts stay neutral; R is 0 so reading it would blacken).
Host hook: `d3d9_carao.patch` (git apply --check ok, NOT compiled/run): in smooth_draw (host/d3d9.c ~2185) look the draw up with cao_find, ask cs_smooth for want_src, write alpha = barycentric AO of the source triangle. Needs decl COLOR0 (`sk[0]`). RN_CARAO=0 = off. Draws < 40 tris are not smoothed, so they get no AO (mirrors, lights: fine). Web: carao.bin must be served like the remaster packs (the patch uses fopen; native only).
VS/PS change (sm1.c, not touched): car VS 0x4728b668 gets one more input v3 = COLOR0 and passes `o.t4 = vec4f(i.v3.w, 0, 0, 0)` (VO has t0..t7 and the car VS writes only t0..t3; sm1.c must set input bit 3 for SM1_CAR_VS, mask `s->inputs` ~line 502, then gpu.js ~628 maps it through the decl by itself: needs COLOR0 in the decl, unchecked). In car_ps_detail: `let ao = mix(1.0, i.t4.x, S);` and `dk0 *= ao` ONLY (car_ps_tail multiplies dk into f.xyz = diffuse; rk/env/specular untouched = no new reflection). S ~0.8 behind a switch (?carao=0). Cost: 1 attribute + 1 varying + 1 mul per pixel, nothing per frame on the CPU.
Brightness rule (OWNER): pack.py drops occlusion below CUT=0.15 and stretches the rest, forces HEADLIGHT/BRAKELIGHT/BASE_* to 255 (open); on body panels mean AO is ~0.95-0.98 (350Z KIT00_BODY 0.95), so open paint is unchanged and only creases darken. Bumpers/spoilers keep more shade (mean 0.7-0.8, thin shells). Shader: `ao = mix(1, a, S)`, default S = 0.4, ?carao=0 -> S 0 = bit-identical to today. AO is from the stock shell + one kit + one style, not every kit x style pair.
Lanes B/C: see NOTES_B.md (LOD is already A for all parts, kits share the body path: not the cause of flat kits), NOTES_C.md (kits have no texture of their own, they use <CAR>_SKIN1).
