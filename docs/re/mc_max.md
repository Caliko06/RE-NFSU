## Open/unknown

- Handedness of the level space and the exact sign convention of the view matrix passed to SetTransform(VIEW): the code path is clear (P_Scene::render passes camera+0x8c to DRV_setViewMatrix 0x10429850), the inverse step is not located.
- Default and runtime FOV values; the projection matrix numbers. Only the call chain (setFOV 0x10113a50, getProjectionMatrix 0x10114c70, SetTransform(3) in 0x10415ef0:217) is known.
- Any function that gives "floor height at (x,z)". The only ground contact is the sweep 0x647da0 into contacts 0x8b4c10 plus snapToGround 0x647df0; the contact record fields beyond normal (+4) and object (+0x24) are not decoded.
