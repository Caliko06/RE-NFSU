The reverse engineering toolbox: Ghidra, Hopper, REA and a census of names

Recompiling a game makes it run. Changing it, fixing it or adding options means understanding it, and a 2003 executable comes with no names, no symbols and no comments.

Updated November 17, 2026

The tools

  • Ghidra, run headless from scripts: the whole executable decompiled to C-like code in four address ranges, saved as text so any search tool can read it.
  • Hopper, a disassembler for macOS: a second decompiler with its own opinion of each function, exported the same way.
  • REA, a reverse engineering server that AI agents talk to over MCP (Model Context Protocol): open the binary, read a function's pseudocode, list who calls an address, read raw bytes.
  • objdump and Capstone for the plain instruction listing, the last word when the decompilers disagree.
  • The running game: a trace switch logs every Windows and DirectX call with its arguments, so a guess about a function can be checked against what it really does.

Two tools or it does not count

Decompilers are wrong in small ways: a missed argument, a float read as an integer, a jump table cut short. So the project has one rule: every value, file format or patch names what proves it (an address in the executable, a chunk id in a data file, a line in the code), read with REA plus a second tool. What is not proven is written down as UNKNOWN, and nothing is built on it.

A census instead of a wiki

Names are stored as plain tables, one per system: cars, camera, collision, menus, audio, the rival AI. Each row is an address, a name and a mark: V when it was read in the code, I when it was inferred, U when unknown. Today there are 55 of those tables with 10,742 rows, next to a census of the 14,330 function entries in Speed.exe. A table can be grepped, diffed and checked by a script; a page of prose cannot.

An example

The phone controls needed a BACK button. Instead of faking a key press and hoping, the input code was read until the menu's action table showed up (address 0x7032d8): one of its actions is Back, and its keys are Escape and Backspace. The touch button sends exactly that key, and the game does the rest the way it did in 2003.

Notes per system

Each investigation leaves a short note in docs/re/: how the camera follows the car, how rivals choose a line, how the game loads a track. They are maps for the next person, not essays. All of it is on GitHub. The work itself was done with AI agents under these rules: how that worked.
