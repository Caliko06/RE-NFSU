From 65.7 to 28.2 seconds: hosting a 2 GB PC game on Cloudflare R2

A hard drive in 2003 answered a read in a few milliseconds. A server on the other side of the world answers in tens. The game does not know the difference, and it reads a lot.

Updated November 17, 2026

The whole game, music included

The public pack is 1.95 GB: the recompiled program, the game's data, every licensed song and the movies. Nothing is cut. The program itself, speed.wasm, is about 70 MB and travels gzipped in about 16 MB. The first visit fetches about 42.5 MB to reach the main menu; tracks and cars arrive when the game asks for them.

Where it is hosted

  • Cloudflare R2 holds the files. Downloads from R2 cost nothing, which matters for a 2 GB game.
  • Three response headers (Cross-Origin-Opener-Policy, Cross-Origin-Embedder-Policy, Cross-Origin-Resource-Policy) turn on cross-origin isolation, which the browser requires before it shares memory between the game's threads.
  • Pages and scripts are never cached at the edge; game data is cached for a day. Scripts carry the build number in their address, so a new build is never mixed with an old one.

The measurement that found it

On our heaviest test route, from the link to driving, the live site took 65.7 seconds. The download size was not the problem. A capture of every request showed 516 byte range requests in a row, each waiting about 75 ms for the previous one: the game reads a file, then the next, exactly as it did on a hard drive, and each read now costs a round trip.

The fix

  • A file up to 8 MB is fetched whole on its first read and kept, so its later reads cost nothing.
  • A list of what the game always read on that route, recorded from real visits, let four prefetch threads fetch those files before the game asked.

On a test server with an 80 ms delay added to every request, the same route went from 66.3 to 22.7 seconds. On the live site, a first visit went from 65.7 to 28.2 seconds, and a second visit, with the browser's cache warm, to 21.4.

The loader is host/files.c and the measuring tool is tools/loadcap.mjs. To see the result, open the game.
