Guides

NFSU.cc is Need for Speed Underground (2003) running in a browser tab. These pages explain how to start, how to drive and what is under the hood.

  • How to play Need for Speed Underground online in your browserOpen nfsu.cc, press Play and drive. What you need, how big the first load is, where your saves live and what to do if the game does not start.
  • Controls: keyboard, gamepad and phoneEvery key and button of Need for Speed Underground in the browser: default keyboard keys, gamepad layout, touch buttons on phones and how to remap them.
  • Browsers, phones and performance settingsWhich browsers and devices run Need for Speed Underground at nfsu.cc, what phones get, and what each quality level and performance option changes.
  • How it works: a 2003 Windows game recompiled to WebAssemblyNFSU.cc is not an emulator or a remake. The original Need for Speed Underground program was translated to WebAssembly and its Windows and DirectX calls were rebuilt on WebGPU.

How it was made

  • Static recompilation: turning a 2003 x86 .exe into WebAssemblyHow the NFSU.cc lifter reads Speed.exe with Capstone, writes every one of its 13,760 functions as C, compiles them with Emscripten and checks them bit for bit against Unicorn.
  • The reverse engineering toolbox: Ghidra, Hopper, REA and a census of namesWhich disassemblers and decompilers were used to understand Need for Speed Underground, and the one rule that kept the work honest: no address is trusted until two tools agree.
  • DirectX 9 and Windows XP rebuilt on WebGPU, Web Audio and workersThe recompiled game still calls Windows and DirectX. This is the layer that answers: a Radeon 9800 that draws with WebGPU, a sound card made of an AudioWorklet, and a hard drive that lives on a server.
  • From 65.7 to 28.2 seconds: hosting a 2 GB PC game on Cloudflare R2Why a game built for a hard drive was slow over the internet, how one measurement found the cause (516 requests in a row), and the setup that serves 1.95 GB with the music included.
  • Reverse engineering a game with AI agents: what workedNFSU.cc went from the first commit to a public site in four weeks, with Claude, Codex and OpenCode agents doing the reading, patching and testing. The rules that kept them from guessing.
