## Reading (V from the code above, I where marked)
- VS: v0 pos, v1 NORMAL, v2 UV. V = normalize(c17 - pos); d = max(N.V, 0.01); (d^k) via log/exp with c22.x / c23.x -> Fresnel-like term in oD1.w and oD0.
- Reflection vector R = 2(N.V)N - V, then oT0 = R x c14 (3x3): texture 0 is an ENVIRONMENT CUBE MAP read with R. oT1 = UV (texture 1 = diffuse).
- Lighting = 9 spherical-harmonic coefficients c0..c9 evaluated on the normal (diffuse, oD0) and on R (reflection tint, oD1), all PER VERTEX.
- PS: env(t0) x4 x (v1.w*c1 + c0) + v1; diffuse(t1) x2 x v0 = r1; out = r0*r1.a + r1: the diffuse ALPHA is the reflectivity mask.
- So the original already has cube reflections + Fresnel + SH lighting on cars. Per-vertex evaluation on faceted meshes is why it reads faceted (I).
